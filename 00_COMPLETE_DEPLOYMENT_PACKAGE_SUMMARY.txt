DEPLOYMENT STEPS (Quick Reference)
================================================================================

STEP 1: Upload Files (5 min)
   Copy all files from COMPLETE_CODE_PACKAGE.md to server following
   the folder structure in FILE_MANIFEST.md

STEP 2: Install Dependencies (3 min)
   composer install

STEP 3: Configure Environment (2 min)
   cp .env.example .env
   nano .env
   Update: database password, app.baseURL

STEP 4: Create Database & Migrate (5 min)
   mysql -u root -p
   CREATE DATABASE beneficiary_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   EXIT;
   php spark migrate
   php spark db:seed RoleSeeder
   php spark db:seed UserSeeder

STEP 5: Set Permissions (2 min)
   chmod -R 755 app/ public/ writable/
   sudo chown -R www-data:www-data .

STEP 6: Restart Web Server (1 min)
   sudo systemctl restart apache2 (or nginx)

STEP 7: Test (2 min)
   Visit: http://yourdomain.com
   Login: admin@example.com / password123
   Check dashboard loads

SUPPORT & TROUBLESHOOTING
================================================================================

If something goes wrong:

1. CHECK LOGS:
   tail -f writable/logs/log-*.log

2. REFER TO GUIDE:
   DEPLOYMENT_SETUP_GUIDE.md → Part 7: Troubleshooting

3. COMMON ISSUES:
   ├── 404 errors: Enable mod_rewrite (Apache)
   ├── Database errors: Check .env credentials
   ├── Permission errors: chmod -R 755 writable/
   ├── Class not found: composer dump-autoload
   └── Blank page: Check error logs

4. DATABASE ISSUES:
   - Verify MySQL is running: sudo systemctl status mysql
   - Test connection: mysql -u root -p
   - Check permissions: SELECT * FROM information_schema.TABLES
